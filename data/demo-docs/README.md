# Dokumen Demo (Fiktif)

Seluruh dokumen di folder ini adalah **dokumen fiktif untuk keperluan demo — bukan rujukan hukum**,
milik perusahaan fiktif PT Demo Rekayasa Indonesia.

- `*.md` = sumber yang diedit (front matter berisi judul, jenis, nomor, tanggal berlaku).
- `docx/*.docx` = hasil `npm run docs:build`; dipakai oleh pipeline ingest. Jangan diedit langsung.

Konflik yang disengaja untuk uji F5: `10-memo-perubahan-batas-klaim.md` (berlaku 1 Agustus 2026)
mengubah batas klaim perjalanan dinas dari 14 hari kalender (PP Pasal 23 ayat 2 dan SOP Klaim Bagian 5)
menjadi 7 hari kerja.
